## Bug Report

**Title:**  
"Read Guide" button is not clickable — no action triggered on click  

**Severity:**  
High  
**Priority:**  
Medium  

**Environment:**    
- OS: Windows 11  
- Browser: Chrome 135.0.7049.85  
- Screen resolution: 2560x1440
  
**Steps to Reproduce:**  
1. Open the page: [https://registry-staging.onrender.com/](https://registry-staging.onrender.com/)  
2. Locate the **"Read Guide"** button.
4. Click on the button.
   
**Expected Result:**  
When clicking the **"Read Guide"** button, the user should be redirected to the guide page.

**Actual Result:**  
The button does not respond to clicks.  
No actions are triggered, and the expected behavior does not occur.  
No errors or logs appear in **DevTools → Console**.  
**Additional Information:**    

**DevTools → Elements:**  
HTML structure:  
```
<button class="inline-flex items-center justify-center whitespace-nowrap transition-colors focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:pointer-events-none disabled:opacity-50 bg-[#1C1C1C] text-primary-foreground border-2 border-grey-800 shadow hover:bg-primary/90 font-semibold px-4 py-3 h-10 text-base leading-[0.875rem] rounded-xl">Read Guide</button>
```
- The `disabled` attribute is **not present**.  
- `pointer-events: none` style is **not applied**.  
- The button is **not overlapped** by another element.  
**DevTools → Console:**  
After selecting the button and running:
```javascript
$0.onclick
```
the result is `null`.  
This confirms no click handler is assigned to the button.
