## Bug Report

**Title:**  
"Looking for a pattern from the old registry?" message lacks context — unclear purpose of the link.

**Severity:** Low )  
**Priority:** Medium 

**Environment:**  
- OS: Windows 11  
- Browser: Chrome 135.0.7049.85  
- Screen resolution: 2560x1440  

**Steps to Reproduce:**  
1. Open the page: [https://registry-staging.onrender.com/](https://registry-staging.onrender.com/)  
2. Locate the message:  
   _"Looking for a pattern from the old registry? Click here"._  

**Expected Result:**  
The message should contain clear information explaining:  
- what the "old registry" is referring to;  
- why the user might want to click the link;  
- whether the patterns are still usable.
A tooltip, helper text, or short description should clarify the context.

**Actual Result:**  
The message appears without any additional explanation.  
It is unclear what the "old registry" refers to and why the user should click the link.

**Impact:**  
Poor user experience (UX):  
- Users might get confused or be unaware that relevant data could still exist in the "old registry".
