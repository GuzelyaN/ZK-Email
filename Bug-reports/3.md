## Bug Report #3

**Title:**  
Incorrect toggle default state for "Anonymous Usage Data" — mismatch between UI state and description

**Date tested:** 14 April 2025

**Severity:** Low 

**Priority:** Medium 

**Environment:**  
- OS: Windows 11, Android 14.0, iOS 18.3.2 - **the issue persists on all.**
- Browser: Chrome 135.0.7049.85, Firefox 137.0.1, Microsoft Edge 135.0.3179.73 - **The issue is resolution-independent and reproducible on any screen size.**
- Screen resolution: 2560x1440, 1024x1366, 430X932 - **the issue persists on all.**
- Device: Windows laptop connected to a 27-inch monitor (only monitor screen being used), OnePlus 10T, iPhone 14Pro - **the issue persists on all.**

**Steps to Reproduce:**  
1. Open the page: https://registry-staging.onrender.com/
2. Click on the button "Log In"
3. Authorize via GitHub
4. Click on the button "Create Blueprint"
5. In the first form of creation, locate the toggle "Anonymous Usage Data" at the top of the form

**Expected Result:**  
The toggle should be in the Enabled (On) state by default, as the text indicates:
"We collect anonymous usage data to improve the registry. Toggle this switch to opt out."
This implies that data collection is active unless the user manually disables it.

**Actual Result:**  
The toggle is in the Disabled (Off) state by default, despite the text indicating that data collection is enabled by default.

**Impact:**  
The mismatch between UI state and description may confuse users, leading to incorrect assumptions about their data-sharing preferences.
